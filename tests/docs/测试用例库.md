# CS2 Tactics Suite — 测试用例库

## 用例编号规范

格式：`TC-{模块}-{编号}`

| 模块代号 | 模块名称 |
|---------|---------|
| AUTH | 认证模块 |
| PUB | 公共接口 |
| ADM | 管理后台 |
| SEC | 安全测试 |
| UNIT | 单元测试 |
| E2E | 端到端测试 |
| PERF | 性能测试 |
| ERR | 错误场景 |
